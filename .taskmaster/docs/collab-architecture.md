# ClaudePPT 팀 협업 — 확정한 방향

2026-11-25 · 원본 0.7.0 기준 · Task Master 태그 `collab`(협업, 먼저) · `master`(최적화 · 고장, 그다음)
자동 작업 규칙은 `.taskmaster/docs/autorun.md`.

## 0. 한 줄

내 PC 의 ClaudePPT 가 호스트가 되고, 팀원은 **초대 링크로 브라우저에서** 들어와 같은 PPT 를 보면서 **Claude 에게 시키고 · 직접 고치고 · 의견을 남긴다.**
Claude 는 전부 내 PC 에서 내 계정으로 돈다. 장표는 처음 고친 세션에 붙고, 누가 시켰는지 모두 남는다.

## 1. 확정한 원칙 (사용자가 정함)

| # | 원칙 |
| - | - |
| 1 | **들어오기** — 줌처럼 초대 링크 하나. 따로 인증 없음. 같은 와이파이든 밖이든 같은 링크. 팀원은 설치 없이 브라우저만 |
| 2 | **Claude** — 팀원 모두 호스트의 Claude 계정을 쓴다. 팀원의 Claude 계정은 상관없다(없어도 된다). Claude 는 호스트 PC 에서만 돈다 |
| 3 | **세션** — 장표는 처음 고친 세션으로 확정. 그 뒤 누가 고치든 그 세션을 이어 쓴다. 처음 보는 장표는 마지막에 쓰인 세션. 새 세션은 「새 대화」로만. 대화칸은 한 세션씩 · 세션 목록 · 보낼 곳 미리보기 (`feat/team-sessions` 에서 만듦) |
| 4 | **누가 시켰나** — 요청 · 직접 편집 · 판마다 사람 이름. 호스트 앱은 설정 「내 이름」, 브라우저 팀원은 링크로 처음 들어올 때 이름 한 번(브라우저가 기억) |
| 5 | **담당 없음** — 쪽 · 권한을 나누지 않는다. 누구나 모든 장표를 고친다 (fork 에서 걷어냄) |
| 6 | **브라우저 팀원도 직접 편집** — 글자 고치기 · 끌어 옮기기 · 방향키. 호스트가 한 줄로 받아 원본에 쓴다 |
| 7 | **호스트만** — PPTX 내보내기 · 릴리즈 · PowerPoint 확인 · 글꼴 설치 · 설정 |

하지 않는 것: 팀원 PC 에서 Claude 실행, 사람마다 다른 Claude 계정, 한 장표의 같은 글자를 동시에 고치는 공동 편집(CRDT), 담당식 권한.
알릴 것: 팀 전체 사용량이 호스트 계정 한도로 모이고, 개인 구독을 여럿이 쓰는 것은 약관 확인이 필요하다.

## 2. 구조

```
 호스트 PC — ClaudePPT (Tauri 2)
   코어(Rust): 덱 저장 · git(판 잠금, 비동기) · 협업 서버(axum: /j/<토큰> · /app · /deck · /ws · /api)
   호스트 화면(WebView2): 사용자 화면 + 쓰기 처리기(remote.ts 길) + 그리기 일꾼(내보내기 · 썸네일)
   Claude 세션들: 장표 세션 규칙(routeOf) · 세션마다 대기열 · 다른 세션끼리 동시
   바깥 길: Tailscale Funnel / Cloudflare quick tunnel 감지 → 주소를 링크에
        │ HTTPS + WebSocket (같은 링크, 사무실 안 · 밖)
   팀원 브라우저들 — 같은 React 화면, 원격 전송층(api.ts 를 transport 로)
```

- **쓰기는 한 곳**: 팀원의 요청 · 직접 편집 · 의견은 「의도」로 호스트에 가고, 호스트가 덱별로 한 줄로 세워 적용한다. 원본 바깥 CLI 처리기(`control.rs` → `remote.ts`) 길을 넓힌다.
- **사건**: 파일 변경 · 턴 글자(30ms 묶음) · 세션 · 판 · 접속(누가 어느 쪽) · 의견을 WebSocket 으로. 일련번호로 재접속 때 놓친 것을 다시 받는다. SSE 는 쓰지 않는다(quick tunnel 미지원).
- **보안**: 원격 API 는 허용 목록뿐(`abs_*` · root 를 받는 `fs_*` · 설정 · claude 경로는 원격에 없음). 모든 요청에 링크 토큰 또는 기기 쿠키. IP 로 믿지 않는다(터널은 127.0.0.1 로 보임). 슬라이드 HTML 에 CSP.
- **대역폭**(Funnel 은 느릴 수 있다): 캐시(ETag · immutable), 썸네일 PNG, 글꼴 나눠 받기, 압축, 지금 쪽 먼저.
- **직접 편집 충돌**: 같은 쪽을 누가 고치는 중이면 「○○ 이 고치는 중」을 보인다. Claude 가 그 쪽을 고치는 턴이 도는 동안은 직접 편집을 받지 않는다(지금 동작). 같은 요소를 둘이 고치면 나중 것이 이긴다.

## 4. 근거로 확인한 사실

- 화면 → Rust 길은 `api.ts` 한 곳, 슬라이드 제공 `serve()` 는 독립 함수(`lib.rs`), Tauri `asset_resolver()` 로 내장 화면을 HTTP 로 다시 줄 수 있다.
- Claude Code 2.1.x: `--session-id` · `--resume` · `--fork-session` · `--settings` · `--safe-mode` 에서도 권한 규칙 동작.
- Cloudflare quick tunnel: 동시 요청 200 · SSE 미지원 · 주소가 매번 바뀜. Tailscale Funnel: 443/8443/10000, 대역폭 제한(비공개).
- 원본 관리자(이슈 #1): 협업은 「설정 › 협업」 스위치(기본 꺼짐) 뒤 · 켜기 전엔 지금 쓰는 사람에게 바뀌는 것 없음 · PR 하나에 한 가지.
