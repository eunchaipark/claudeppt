## 2. 띄우는 법

```
git fetch origin
git checkout collab
npm install
npm run tauri dev          # 개발 실행
```

설치 판으로 보려면 `npx tauri build` → `src-tauri/target/release/bundle/nsis/` 의 설치 파일. (빌드만 한 실행 파일은 `src-tauri/target/release/claudeppt.exe`)

- 설정 › 일반 「내 이름」을 정해 두세요(호스트의 이름이 요청 · 판에 남습니다).
- 설정 › **협업** 에서 「협업 켜기」. 처음 켤 때 Windows 방화벽이 물으면 **허용**(같은 와이파이의 다른 PC 가 들어오려면 필요).

## 3. 제가 이미 확인한 것 (요약)

- 자동 시험: `npx tsc --noEmit` 통과, `cargo test --lib` 24개 통과(판 작성자 · 경로만 판 남기기 · git 설정 격리 · 세션 기록 · job · 링크 · 기기 · 출처 · 터널 주소 읽기 등)
- 같은 PC 에서 **Edge 를 다른 프로필로 띄워 이 PC 의 사무실 망 주소(10.x.x.x:47815)** 로 들어가 호스트 ↔ 브라우저를 오가며:
  - 공용 링크 → 이름 화면 → 들어옴, 개인 링크 → 바로, 잠금 중 새 사람 거절, 내보내기 → 즉시 끊김
  - 호스트가 고친 쪽 · 쪽 추가 · 대화 글자 흐름이 브라우저에 바로 · 서로 보는 쪽(머리글자)
  - 브라우저에서 새 대화 · 요청 · 첨부 · 직접 편집(실제로 두 번 눌러 입력) · 되돌리기 · 의견 · 세션에 보내기
  - 진짜 Claude 도 브라우저에서 한 번(시험 동안만 sonnet · low, 끝나고 opus · xhigh 로 되돌림)
  - 협업 껐다 켜기 · 앱 다시 띄우기 뒤 브라우저가 저절로 다시 붙음
- **설치 판(release 빌드)** 으로도 띄워 봤습니다: 협업 서버가 앱에 담긴 화면을 내주고(`/assets/index-….js`, immutable · gzip 862KB → 282KB), 장부(링크 · 기기)가 이어져 민수가 링크 없이 다시 들어왔습니다(`shots/c17-release.png`). 설치 파일(nsis)로 깔아 보지는 않았습니다.
- 쓰시던 덱 「제목 없음」은 건드리지 않았습니다. 시험 덱 「제목 없음 2」는 이 안내서를 끝까지 해 보시고 지우셔도 됩니다(제가 마지막에 지웁니다 — 남아 있으면 지워 주세요).

## 4. 직접 해 보실 시험

### A. 이 PC 한 대 (5분)

1. 앱에서 덱 하나를 엽니다(새로 만들어도 됨). 설정 › 협업 › 「협업 켜기」.
   - 기대: 초대 링크(공용)가 보입니다. 제목 줄에 「1명 접속」.
2. 「복사」를 눌러 링크를 **다른 브라우저**(크롬 · Edge 시크릿 창)에 붙여 엽니다.
   - 기대: 이름 화면 → 이름(예: 민수)을 적고 「들어가기」 → 같은 덱이 보입니다. 주소창에 열쇠가 남지 않습니다.
3. 호스트 앱에서 쪽을 넘겨 보세요.
   - 기대: 브라우저 쪽 목록 · 무대 오른쪽 위에 호스트 이름 머리글자가 그 쪽에 보입니다. 브라우저에서 넘기면 호스트에도 보입니다.
4. 브라우저 대화칸에서 요청을 보냅니다(예: 「@1 제목을 더 짧게」).
   - 기대: 호스트 대화칸에도 같은 턴이 「민수」로 보이고, 글자가 양쪽에 함께 흐릅니다. 끝나면 판 목록에 작성자 민수.
5. 브라우저에서 1쪽 글자를 두 번 눌러 고치고 Enter.
   - 기대: 호스트 무대에 「민수 님이 이 쪽을 고치는 중」, 몇 초 뒤 판 「민수 직접 편집」.
6. 브라우저에서 핀(의견)을 꽂고 글을 적습니다.
   - 기대: 호스트에 「민수 님이 1쪽에 의견을 남겼습니다」, 대화 머리 「의견 1」. 호스트에서 「세션에 보내기」를 누르면 「민수 님이 남긴 의견을 반영해 줘」 턴.

### B. 같은 와이파이의 다른 PC · 휴대폰 (10분)

1. 호스트 앱 설정 › 협업의 링크(맨 앞 주소가 `http://10.…:47815/j/…` 꼴)를 다른 PC 나 휴대폰(같은 와이파이)으로 보냅니다.
   - 기대: A 와 같은 흐름. 안 열리면 방화벽(호스트 PC 에서 ClaudePPT 허용)을 보세요.
2. 두 사람이 **다른 쪽**에 거의 같이 요청해 보세요(각각 다른 세션이 붙은 쪽).
   - 기대: 두 턴이 함께 돕니다. 같은 쪽 · 같은 세션이면 뒤 요청은 「대기 중」으로 섰다가 이어 돕니다.
3. 한 사람이 같은 쪽을 고친 뒤 다른 사람이 같은 쪽을 고치고, 앞 사람이 Ctrl+Z.
   - 기대: 「그 뒤에 다른 사람이 이 쪽을 고쳐서 되돌리지 않았습니다」(남의 것을 지우지 않음).

### C. 바깥(휴대폰 LTE 등) — 도구 설치 필요

1. 호스트 PC 에 cloudflared 를 깝니다: `winget install Cloudflare.cloudflared` (계정 필요 없음). 또는 Tailscale 을 깔고 관리 화면에서 Funnel 을 허락.
2. 앱을 다시 띄워 협업을 켭니다.
   - 기대: 설정 › 협업 › 「바깥에서도」에 `https://….trycloudflare.com`(또는 `….ts.net`)이 열리고, 초대 링크가 그 주소로 바뀝니다. 제목 줄 「바깥 열림 · n명」.
3. 휴대폰(LTE, 와이파이 끔)으로 링크를 엽니다.
   - 기대: 들어와서 대화 글자가 흐르는지(WebSocket 이 터널을 지나는지)가 핵심입니다. **이것은 제가 확인하지 못했습니다.**
   - Cloudflare 주소는 켤 때마다 바뀝니다 — 다시 켜면 링크를 다시 보내야 합니다.

## 5. 알려진 한계 · 남은 일

- **원본 PR 전에 정할 것**: 이슈 #1 에 관리자 답 대기(담당을 이 방식으로 바꿀지 / 스위치 뒤에 따로 둘지). 계획은 `.taskmaster/docs/upstream-plan.md`.
- fork 에 원본 최신 두 커밋(라이선스 · README)을 올리지 못했습니다 — gh 토큰에 workflow 권한이 없어서입니다. `gh auth refresh -s workflow` 를 해 주시면 fork main 을 맞추고 collab 에 합칠 수 있습니다.
- 팀원 세션(세션 목록 · 보낼 곳 · 이름)은 collab 에서는 늘 켜져 있습니다. 원본 규칙(스위치 뒤)에 맞추는 것은 관리자 답 뒤에.
- 다른 PC 에 없는 글꼴은 브라우저에서 대체 글꼴로 보입니다(덱 `assets/fonts` 에 든 글꼴은 그대로 감). 호스트 글꼴을 내주는 것은 라이선스 · 크기 때문에 보류.
- 쪽이 많으면 브라우저 쪽 목록이 무겁습니다(쪽마다 iframe, 두 번째부터는 캐시).
- 함께 도는 두 세션이 덱 구성(deck.json, 쪽 더하기 · 순서)을 동시에 고치면 마지막에 쓴 것이 남습니다. 같은 쪽은 세션을 미리 붙여 막습니다.
- 개발 실행에서 코드를 고치면(HMR) 브라우저 쪽이 연결을 잃은 듯 보일 수 있습니다 — 새로 고치면 됩니다(설치 판에는 없음).
- 내보내기 · 릴리즈 · 설정 · 덱 열기는 호스트만 합니다(브라우저에는 단추가 없음).
