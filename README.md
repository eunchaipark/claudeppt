# ClaudePPT

Claude 와 대화하며 발표 자료를 만들고, PowerPoint 에서 그대로 고칠 수 있는 PPTX 로 내보내는 Windows 데스크톱 앱.

A Windows desktop app for building slide decks by talking to Claude, then exporting them as editable PowerPoint files. The UI is in Korean and English.

[내려받기](https://github.com/a7garden/claudeppt/releases/latest) · [바뀐 것](CHANGELOG.md) · [기여 안내](CONTRIBUTING.md)

## 무엇을 하나

- **말로 만든다.** 「분기 실적 보고 10쪽」처럼 주제를 쓰면 Claude 가 쪽을 짓는다. 고칠 곳은 대화로 말하거나, 쪽 위에 핀 · 펜 · 화살표로 짚어서 맡긴다.
- **보면서 바로 고친다.** 글자는 두 번 눌러 그 자리에서 고치고, 요소는 끌어 옮긴다. Claude 가 고친 쪽은 바로 다시 그려진다.
- **편집 가능한 PPTX 로 낸다.** 글상자 · 도형 · 표는 PowerPoint 에서 고칠 수 있는 꼴로 나가고, PowerPoint 가 같게 그리지 못하는 효과만 그림으로 굳는다. 내보낸 뒤 PowerPoint 로 다시 그려 웹과 픽셀로 견주어 본다.
- **가진 PPTX 를 가져온다.** 원본과 같은 모양으로 옮긴 뒤 이어서 고친다.
- **판이 남는다.** 고칠 때마다 판(v1 · v2 …)이 쌓이고, 어느 판과도 겹쳐 견주고 되돌린다.
- **여럿이 함께 고친다.** 팀원이 초대 링크로 브라우저에서 같은 덱에 들어와 요청 · 직접 편집 · 의견을 남긴다(설정 › 협업). 쪽은 처음 고친 세션에 붙어, 누가 고치든 그 세션을 이어 쓴다.

## 설치

[최신 릴리즈](https://github.com/a7garden/claudeppt/releases/latest)에서 `ClaudePPT_<판>_x64-setup.exe` 를 받아 실행한다. 깔린 앱은 새 판이 나오면 쉬는 틈에 저절로 업데이트한다.

필요한 것:

| | |
| - | - |
| Windows 10 · 11 (64비트) | 화면은 WebView2 로 그린다. Windows 11 에는 들어 있고, 없으면 설치 파일이 받는다 |
| [Claude Code](https://claude.com/claude-code) CLI | 로그인해 둔 것을 그대로 쓴다(구독 · API 키). 앱이 경로를 찾고, 못 찾으면 「설정」에서 고른다 |
| Git | 판 이력을 git 으로 남긴다 |
| PowerPoint (있으면) | 가져온 PPTX 의 원본 쪽 그림 · 내보낸 PPTX 확인에 쓴다. 없어도 만들기 · 내보내기는 된다 |

## 처음 써 보기

1. 앱을 켜고 홈 화면의 「주제」 칸에 만들 자료를 한 줄로 쓰고 Enter.
2. Claude 가 쪽을 짓는 동안 왼쪽 쪽 목록 · 가운데 무대에 쪽이 하나씩 나타난다. 오른쪽 대화칸에 「표지를 더 단순하게」처럼 고칠 것을 쓴다.
3. 다 되면 「내보내기」(Ctrl+E) › 「PowerPoint 고칠 수 있게」.

가진 PPTX 에서 시작하려면 파일을 창에 끌어 놓는다.

## 쓰는 법

아래는 화면마다 할 수 있는 일을 모두 적은 표다.

| 하고 싶은 것 | 길 |
| - | - |
| 새로 만들기 | 홈 화면의 「주제」에 한 줄을 쓰고 Enter: 빈 덱을 만들고 그 글로 첫 턴을 보낸다. 비워 두고 누르면 표지 한 장만 |
| PPTX 가져오기 | 「PPTX 가져오기」(Ctrl+O) 또는 창에 끌어 놓기(홈 화면 · 작업 화면 어디서나. 끌어 오는 동안 무엇을 어떻게 가져오는지 판으로 보인다). 원본과 같은 모양의 HTML 로 옮기고, PowerPoint 가 있으면 원본 쪽 그림(`source/pages`)도 뽑는다 |
| 고치기 | 오른쪽 대화칸에 쓰고 Enter. 그림 · PDF · 글 파일을 함께 보낼 수 있다(범위 줄의 클립 단추 · 붙여 넣기 · 덱을 연 채 창에 끌어 놓기). 첨부는 덱의 `.claudeppt/attach/` 에 복사되고 지난 요청 칸에도 남는다. Word · 엑셀 · 한글 파일은 Claude 가 읽지 못해 받지 않는다 |
| 대화 접기 | 대화 머리의 판 아이콘 · Ctrl+B 로 오른쪽 대화를 접어 무대를 넓힌다. 접으면 44px 등뼈에 판 마디(누르면 그 판 보기) · Claude 가 도는 중 · 접은 뒤 온 새 답 · 핀 수 · 쓰던 글 표시가 남는다. 「/」 · 핀 꽂기 · 쪽 언급은 저절로 편다 |
| 쪽 지정(@) | 요청칸 아랫줄(범위 줄)이 이 요청이 닿는 곳을 보인다. 아무것도 짚지 않으면 「덱 전체」와 지금 쪽 하나로 좁히는 「n쪽만」, 짚었으면 그 쪽 · 판마다 칩(× 로 뺀다). 요청칸에서 `@` 를 치거나 범위 줄의 「@」를 누르면 쪽 고르기 창(번호 · 미리보기 · 제목)이 뜬다: ↑↓ · Enter 로 넣는다. `@3` 은 3쪽, `@3-5` 는 3~5쪽. 쪽 목록 번호 옆 `@` 를 눌러도 들어간다. Claude 에게는 그 쪽들의 파일이 함께 가고, 지난 대화의 `@쪽` 을 누르면 그 쪽으로 간다 |
| 판 언급(@v) | 요청칸에서 `@v` 를 치면 판 고르기 창: `@v12` 는 12판. 보낼 때 그 판의 덱 파일을 `.claudeppt/versions/v12/` 에 펼치고 지금과 다른 쪽을 적어 넘겨, Claude 가 참고로 읽는다(「@v12 의 표지 배치로」). 판 목록 · 지난 판 보기 · 비교 띠 · 대화의 판 우클릭에서도 넣는다 |
| 넘겨 보기 | 무대 위에서 휠 · ↑↓←→ · PageUp/Down · Home/End 로 쪽을 넘긴다. 제목 줄 가운데 「한 쪽 · 이어 보기」(S): 이어 보기는 모든 쪽을 세로로 늘어놓고 스크롤로 넘긴다. 가운데 온 쪽이 지금 쪽, 두 번 누르면 그 쪽을 「한 쪽」으로 크게 연다 |
| 우클릭 메뉴 | 영역마다 그 자리에서 할 일을 띄운다. 쪽 목록 · 이어 보기: 이 쪽 언급 · 위/아래에 새 쪽 · 복제 · 앞/뒤로 옮기기 · 쪽 삭제. 무대: 여기에 핀 · (편집 중) 이 요소 지우기 · 보기/핀/편집 · 이어 보기 · 비교. 대화: 요청 다시 쓰기 · 답 복사 · 그 판 보기/되돌리기 · 지금과 비교 · 이 판 언급. 판 목록: 보기 · 되돌리기 · 지금과 비교 · 이 판 언급. 입력칸: 실행 취소 · 잘라내기 · 복사 · 붙여 넣기 · 모두 선택. 고른 글이 있으면 맨 위에 「복사」 |
| 도구 띠 | 모드를 따로 바꾸지 않는다. 슬라이드 위 도구 띠: 선택(V) · 펜(1) · 화살표(2) · 범위(3). 선택이 기본: 보면서 바로 고친다(아래 「직접 편집」). 펜 · 화살표 · 범위는 끌어서 긋고(범위는 네모로 묶기), 끌지 않고 누르면 핀. 표시마다 번호와 의견 칸이 붙고, 여러 쪽의 표시가 요청칸 위에 쌓여 보내기 한 번에 함께 간다. 이어 보기에서도 쪽마다 긋는다(글자 고치기 · 끌어 옮기기는 한 쪽 보기에서). 보낼 때 표시를 그려 넣은 쪽 그림(`.claudeppt/attach/marks-*.png`)을 붙여 Claude 가 어디를 가리키는지 본다. Ctrl+Z 는 이 쪽의 마지막 표시 지우기 |
| 쪽 끌어 놓기 | 쪽 목록 · 이어 보기의 쪽을 요청칸에 끌어 놓으면 `@쪽` 이 들어간다. 쪽 목록 안에서 끌면 순서 바꾸기 |
| 직접 편집 | 선택 도구(V)에서 글자 고치기: 두 번 누르기(누른 낱말이 골라진다) · 고른 글자를 한 번 더 누르기(누른 자리에 커서) · 고른 요소에서 Enter · F2(글 전체). Enter 로 마치고 Esc 는 취소, Shift+Enter 는 줄 바꿈, 붙여 넣기는 글자만. 절대 위치 요소 끌어 옮기기 · 고른 요소는 방향키 1px(Shift 10px) · Delete 로 지우기. 아무것도 고르지 않았으면 방향키는 쪽을 넘긴다. 원본 HTML 에 되쓰고 잠잠해지면 한 판으로 남긴다 |
| 판 | 제목 줄 덱 이름 옆 판 번호(v<n> ▾)를 누르면 판 목록: 새 판이 위, 릴리즈는 꼬리표. 누르면 그 판을 제자리에서 보고 「이 판으로 되돌리기」. 대화의 v 번호도 같은 판이다 |
| 릴리즈 | 제목 줄 「릴리즈」: 이름 · 메모를 적고 확정하면 `releases/r<k>-v<n>.pptx` 를 만들고 git 태그 `r<k>` 를 단다 |
| 내보내기 | 「내보내기」(Ctrl+E): PowerPoint 고칠 수 있게 · 모양 그대로 · CPPT 묶음(폴더째 zip) · 폴더 열기 |
| 비교 | 도구 띠 오른쪽 「비교」(C): 고른 판과 지금을 겹쳐 본다 (아래 「판 비교」). 이 쪽만 그 판으로 되돌리기 · 빠진 쪽 되살리기 |

쪽 목록: 끌어서 순서 바꾸기 · Delete 로 쪽 삭제 · 끝의 + 로 빈 쪽. 무대: ↑↓ · PageUp/Down 으로 쪽 넘기기.

## 프로젝트 파일 꼴 (`claudeppt/1`)

```
<프로젝트 폴더>/
  deck.json            목차: 제목 · 크기 · 쪽 순서 (쪽 순서의 유일한 정본)
  theme.css            모든 쪽이 함께 쓰는 서식 (색 · 글꼴 변수 · .slide 틀)
  slides/<id>.html     한 쪽에 한 파일, <section class="slide"> 하나 (기본 1280×720)
  assets/              그림 · 글꼴 (gen-*.png 는 그림 생성 도구가 만든 것)
  source/              가져온 원본: original.pptx · pages/<n>.png
  releases/            r<k>-v<n>.pptx · releases.json
  .claudeppt/          앱 상태 (핀 · 대화 · 임시): 판에 넣지 않는다
  .git/                판 이력: v<n> = 커밋 수, 릴리즈 = 태그 r<k>
```

저장 폴더(기본 `문서\ClaudePPT`) 아래에 프로젝트 폴더가 쌓인다. 한 파일로 주고받을 때는 `.cppt`(폴더째 zip, 판 이력 포함)를 쓴다.
판 관리에 git 이 필요하다: 사용자의 git 설정(이름 · 줄끝)과 무관하게 앱이 매번 값을 준다.

## 바깥 Claude Code 에서 부리기: CLI + 스킬

앱 안 대화칸 말고, 따로 띄운 Claude Code 세션이 덱을 고칠 수도 있다. 그 세션이 슬라이드 파일을 직접 고치고, 그려야 하는 일은 CLI 로 앱에 시킨다.
앱이 켜져 있으면 고친 쪽이 바로 다시 그려진다: 사용자는 앱으로 보고, 바깥 Claude 는 파일을 고친다.

```
claudeppt.exe skill          # ~/.claude/skills/claudeppt 에 SKILL.md 와 cppt 꾸러미를 쓴다 (앱을 새 판으로 올리면 다시 부른다)
claudeppt.exe help           # 명령 목록
```

- **CLI 는 앱과 같은 실행 파일이다.** 인자를 주면 창 없이 명령으로 돌고 stdout 에 JSON 하나를 찍는다 (`{"ok":true,"data":…,"deck":"<쓴 덱>"}` · 실패면 종료 코드 1).
- **덱 고르기**: `--deck <폴더 | 저장 폴더 안 이름 | 제목>` · 덱 폴더 안에서 부르기 · 앱에 열린 덱 순서. 덱을 바꾸는 명령(`commit` · `restore` · `add` · `remove` · `move` · `gen` · `release` · `pins --done`)은 앱에 열린 덱으로 넘겨짚지 않는다.
  Claude Code 의 Bash 는 작업 폴더 밖으로 간 `cd` 를 되돌려서, 덱 폴더에 `cd` 해 둔 줄 아는 세션이 앱에 띄운 다른 덱에 판을 남길 수 있었다.
- **앱 없이 하는 일**: `list` · `info` · `log` · `commit` · `restore` · `pack` · `unpack` · `add` · `remove` · `move`(쪽 더하기 · 빼기 · 옮기기). 파일과 git 만 본다.
- **앱에 넘기는 일**: `new` · `import` · `open` · `shot`(쪽 PNG) · `inspect`(그림으로 굳는 것 · 넘친 것) · `export` · `check` · `release` · `style`(스타일 · 그림 규칙) · `pins`(핀 의견 · 표시 그림) · `gen`(그림 자리 채우기).
  웹뷰가 쪽을 그려야 하거나 앱 설정 · 앱이 쥔 핀을 써야 해서 실행 중인 앱에 넘기고, 꺼져 있으면 띄운다(덱을 다루는 명령이면 그 덱을 화면에 연다).
  열려 있지 않은 덱도 화면을 바꾸지 않고 처리한다. 오래 걸리는 일은 오른쪽 아래 진행 막대에 「CLI · …」 로 보인다.
- **핀으로 일 시키기**: 사용자가 앱에서 핀 · 표시를 꽂고 바깥 세션에 「핀대로 고쳐」. 바깥 세션은 `pins` 로 앱 안 턴과 같은 글 · 같은 표시 그림을 받고, 고친 뒤 `pins --done` 으로 지운다.
- **통로**: 앱이 켜질 때 `127.0.0.1` 빈 포트를 열고, 화면이 준비되면 포트 · 토큰을 `%APPDATA%\com.seesun.claudeppt\control.json` 에 쓴다(끌 때 지운다).
  한 연결에 JSON 한 줄을 주고받는다. HTTP 가 아니고 토큰이 있어야 해서 웹 페이지 · 슬라이드 스크립트가 두드려도 받지 않는다.
- **앱 안 Claude 와 겹치지 않게**: `status` 의 `running` 이 그 덱이면 덱을 바꾸는 명령은 거절하고(`--force` 로 넘긴다 · `status --wait` 로 기다린다), 앱 안 Claude 가 일하는 동안에는 화면의 덱을 바꾸지 않는다.
  거꾸로, CLI 가 덱을 다룰 때마다 앱에 알리고(`touch`), 앱은 그 뒤 5분 안에 같은 덱에서 앱 안 Claude 에게 보내려 하면 「그래도 보내기」로 한 번 묻는다.
- 바깥에서 고친 파일은 폴더 감시가 잡아 다시 그리지만 판은 저절로 남지 않는다: 스킬이 한 묶음마다 `commit` 을 부르게 한다.
- 스킬 본문의 정본은 저장소 `skill/SKILL.md` 다: 빌드할 때 실행 파일에 담긴다.
- **「설정 › Claude Code 연결」** 에서 관리한다:
  - 명령 받기 켜기/끄기: 끄면 앱에 넘기는 명령을 거절한다. 통로는 열어 두고 ping 에만 답한다. 닫으면 CLI 가 앱이 꺼진 줄 알고 하나 더 띄운다.
  - 스킬 상태(설치 안 됨 · 최신 · 앱과 버전이 다름)와 「설치 · 다시 설치」 · 폴더 열기. 앱을 새 버전으로 올리거나 실행 파일이 옮겨지면 「앱과 버전이 다름」이 된다.
  - CLI 경로 복사 · 최근 바깥 명령 30개(시각 · 명령 · 덱 · 걸린 시간 · 실패 까닭). `commit` · `restore` 처럼 앱 없이 한 일도 앱이 켜져 있으면 남는다.

## Claude 격리

이 앱의 Claude 는 사용자의 다른 Claude 설정에 영향을 받지 않는다. 인자는 `src-tauri/src/claude.rs` 에 고정돼 있어 화면에서 바꿀 수 없다.

- `--safe-mode`: CLAUDE.md · 스킬 · 플러그인 · 훅 · MCP · 출력 스타일을 끈다
- `--setting-sources ""`: 사용자 · 프로젝트 settings.json 도 읽지 않는다 (`--safe-mode` 만으로는 응답 언어 설정이 남았다)
- `--system-prompt-file`: 기본 시스템 프롬프트 대신 이 앱의 프롬프트(`src/lib/prompt.ts`). 화면에서 바꾸지 않는다: 덱의 스타일은 템플릿의 스타일 지침으로 더한다
- `--tools Read,Edit,Write,Glob,Grep`: 셸 · 웹 없음. `--permission-prompts none`: 물을 일이 생기면 기다리지 않고 거절
- 구독 로그인은 그대로 쓴다. 대화는 `--resume` 으로 프로젝트마다 한 세션을 잇는다

## 템플릿 · 그림 설정

- 그림 공급자: **SVG**(기본, Claude 가 직접 그린다) · Codex CLI · Gemini CLI(자동 감지) · OpenAI API · Gemini API(키 등록).
  SVG 가 아니면 Claude 는 `<img data-gen="…">` 자리만 두고, 턴이 끝난 뒤 앱이 공급자로 그림을 만들어 `assets/` 에 넣는다.
  CLI 두 가지는 그 도구가 파일을 정한 자리에 썼는지로 판단한다: Gemini CLI 는 그림 확장(예: nanobanana)이 있어야 한다.
- 템플릿: 덱 만드는 스타일 한 벌(글꼴 · 글자색 · 바탕색 · 강조색 · 모서리 · 선 굵기 · 그림자 · 아이콘(선/면) · 스타일 지침(글로 적는 규칙) · 그림 화풍).
  이름을 붙여 여러 벌 두고, 「새 덱」 표가 붙은 것으로 새 덱을 만든다(홈 화면에서 이번 덱만 다른 것을 고를 수 있다).
  덱은 `deck.json` 의 `template` 에 만든 템플릿을 남기고, 매 턴 그 템플릿의 규칙이 프롬프트에 실린다: 기본 템플릿을 바꿔도 지난 덱은 제 스타일을 따른다.
  가져온 PPTX 는 템플릿 없이 원본 모양을 지킨다. 덱을 열어 두면 「이 템플릿 입히기」(theme.css 의 색 · 글꼴 변수만 바꾼다) · 「이 덱 모양으로 새 템플릿」을 쓸 수 있다.

## PPTX 내보내기: 웹과 같은 모양

쪽마다 화면 밖 iframe 에 1:1 로 그려 런타임(`src-tauri/runtime/rt.js`)이 잰 좌표로 만든다: PPT 쪽에서 배치를 다시 계산하지 않는다.
**PowerPoint 가 같은 모양으로 그릴 수 있으면 편집 가능한 도형으로, 아니면 브라우저가 그린 그대로 구운 그림으로** 넘긴다.

| 웹 | PPTX |
| - | - |
| 단색 바탕 · 고른 테두리 · 둥근 모서리 · 한 변 선 | 도형 · 선 (편집 가능) |
| 안쪽이 인라인뿐인 글자 묶음 | 글상자: 조각마다 크기 · 굵기 · 색 · 자간, **브라우저가 끊은 자리에서 줄을 바꾸고 기준선 높이를 맞춘다** |
| `<table>` | 표 |
| 그라데이션 · 바탕 그림 · 그림자 · `::before/::after` · 고르지 않은 테두리 · 모서리 | 그 요소의 바탕만 구운 그림 + 그 위 글자는 편집 가능 |
| `<img>` · `<svg>` · 변형(회전) · 필터 · 블렌드 · clip-path · 글자 그림자 · 목록 표식 | 자식째 구운 그림 |

- 글꼴 이름은 원본 PPTX 에 적힌 그대로(한글 이름 포함) 쓴다. 웹뷰는 가족 이름으로 영어 이름만 알아보므로, 프로젝트를 열 때 `theme.css` 맨 앞 앱 구획에
  `@font-face { font-family: "에스코어 드림 5 Medium"; src: local("S-Core Dream 5 Medium") }` 꼴 별칭을 쓴다(굵게 · 기울임 판까지). 깔린 글꼴은 이름 표의 모든 나라말 이름으로 찾는다.
  못 찾은 글꼴은 알림의 「맡기기」로 Claude 가 공식 배포처를 웹에서 찾고(주소만 · 파일을 못 건드린다), 앱이 받아 글꼴인지 가려 사용자 글꼴로 깔고 프로젝트 `assets/fonts` 에도 넣는다.
  PPTX 안에 넣어 둔 글꼴(MicroType Express 압축 EOT)은 아직 꺼내지 못한다.
- 내보낼 때 글꼴: CSS 글꼴 목록에서 **이 PC 에 깔린 첫 글꼴**을 고른다(브라우저와 같은 차례). 500 · 600 같은 굵기는 「Pretendard Medium」 · 「Pretendard SemiBold」 처럼 깔린 이름으로 고른다. 깔린 글꼴이 하나도 없으면 알린다.
- 기준선: PowerPoint 는 「정확히」 줄 간격에서 첫 줄 기준선을 약 `0.716 × 줄 높이 + 0.089 × 글자 크기` 아래에 둔다(2026.11.17 크기 12~56px × 줄 높이 1.0~1.8 실측). 브라우저가 실제로 그린 기준선과의 차이만큼 글상자를 옮긴다.
- 「모양 그대로」 내보내기: 쪽마다 웹을 2배로 구운 그림 한 장 + 같은 자리의 투명 글상자(찾기 · 복사용). 글자 획 가장자리까지 같지만 PowerPoint 에서 모양을 고치지 못한다.

## 판 비교

「비교」(C) 는 **고른 판과 지금**을 견준다. 처음에는 직전 판이고, 띠의 판 고르기 · 판 목록 · 지난 판 보기의 「지금과 비교」로 다른 판을 고른다.

- 쪽마다 HTML 글을 견주어 바뀐 쪽 · 새 쪽 · 빠진 쪽을 가린다. theme.css 가 다르면 띠에 「테마도 바뀜」.
- 무대에 비교 렌즈: 가름선 왼쪽은 고른 판, 오른쪽은 지금(슬라이드 아래 모서리 이름표). 끌거나 ←→ 로 옮긴다. 바뀐 곳은 두 판을 1:1 로 구워 빨갛게 덧칠한다.
- 쪽 목록에 바뀐 쪽 · 새 쪽 표시, 띠의 ◀ ▶ 로 바뀐 쪽만 넘긴다.
- 「이 쪽만 v<n> 으로」: 이 쪽 HTML 만 그 판으로 되쓰고 한 판으로 남긴다. 지금 없는 그림은 그 판에서 꺼내 온다. 그 판 뒤에 뺀 쪽은 띠 아래 줄에서 눌러 그 판의 자리에 되살린다.
- 비교 중에 Claude 가 고치거나 손으로 고치면 잠잠해진 뒤 다시 견준다. Esc · 「닫기」 로 끝낸다.

## 내보낸 PPTX 확인: 웹 ↔ PPT

「PowerPoint 고칠 수 있게」 내보내기와 릴리즈가 끝나면 **그 PPTX 를 PowerPoint 로 쪽마다 그리고, 웹을 1:1 로 구운 그림과 픽셀로 견준다**: 화면을 막지 않는 뒤 일로. PowerPoint 가 없으면 확인하지 못했다고만 알린다. 바깥 CLI 의 `check` 도 같은 검사다.

- 모두 같으면 한 줄로 알리고, 다른 쪽 · 그림으로 굳은 쪽이 있으면 그 쪽 번호와 「차이 고치기」를 띄운다.
- 글자 가장자리 흐림 · 1px 어긋남 · 1px 너비의 획 가장자리(두 엔진의 글꼴 힌팅 차이)는 세지 않는다: 남는 것은 눈에 보이는 차이(빠진 도형 · 다른 색 · 2px 넘게 어긋난 글자 · 다른 글꼴)다.
- **그림으로 굳은 곳**도 함께 센다. 변형 · 필터 · 글자 그림자 · 목록 글머리 같은 효과가 걸린 요소는 자식까지 통째로 그림이 되어, PowerPoint 에서 웹과 똑같이 보이므로 차이 0% 로 통과하지만 그 안의 글 · 도형을 고치지 못한다. 결과에 그 요소의 자리와 쪽 넓이 %를 남긴다. `<img>` · `<svg>` 처럼 원래 그림인 것은 세지 않는다.
- 「차이 고치기」 는 차이가 남거나 굳은 곳이 있는 쪽의 웹 · PPT · 차이 그림과 굳은 요소 자리를 붙여 Claude 에게 HTML 을 고치게 한다. 굳은 요소는 같은 모양을 편집 가능한 꼴로 만들 수 있으면 바꾸고, 디자인에 꼭 필요한 효과면 남긴다.
- 결과는 `.claudeppt/check/` (check.pptx · ppt/ · web/ · diff/ · report.json).

2026.11.17 실측: Claude 가 지은 3쪽 덱 0% · 가져온 PPTX(원본 글꼴이 이 PC 에 없음) 0.12~0.18% (대체 글꼴이 다른 몇 글자) · 「모양 그대로」 0.01~0.05%.

## PPTX 가져오기가 옮기는 것

마스터 → 레이아웃 → 쪽 순서로 그리고, 자리 표시자는 위치 · 글자 서식을 위에서 물려받는다. 테마 색(lumMod · tint · shade) · 그룹 좌표 · 표 · 그림 자르기 · 연결선 화살표 · 글머리 · 쪽 번호 필드를 옮긴다.
차트 · SmartArt · EMF 그림 · 자유형 도형은 자리만 점선으로 남기고 알림에 적는다: 원본 쪽 그림을 보고 Claude 에게 「원본과 같게」 다듬기를 맡긴다.

  슬라이드 iframe 에 붙으려면 `CDP_TARGET=<슬라이드 파일 이름>` 을 준다: 거기서는 `window.__rt` 에 bake · extract 가 있다.

### 릴리즈 · 자동 업데이트

- **판 번호 규칙 (2026.11.23)**: 기여 PR 은 판 번호를 올리지 않는다. 병합한 뒤 관리자가 올린다. 고칠 때마다 패치 번호를 하나 올린다(`0.1.2` → `0.1.3`). 사용자가 「릴리즈」라고 하면 마이너 번호를 올리고 패치는 0 으로(`0.1.3` → `0.2.0`) 그 판을 낸다.
  패치 판은 쌓아 두기만 하고 GitHub 릴리즈로 내지 않는다: 깔린 앱이 받는 것은 릴리즈한 마이너 판뿐이다.
- `package.json` · `src-tauri/Cargo.toml` · `src-tauri/tauri.conf.json` 의 버전과 `CHANGELOG.md` 구획을 함께 올리고 커밋한 뒤 `git tag v<버전> && git push origin v<버전>`.
  `.github/workflows/release.yml` 이 설치 파일 · 서명 · `latest.json` 을 GitHub 릴리즈에 올린다.
- 설치된 앱은 켤 때와 1시간마다 `releases/latest/download/latest.json` 을 보고 새 판이면 제목 줄에 「업데이트 <번호>」 칩이 서고, 처음 찾은 판은 설명을 저절로 편다.
  **자동 설치**(기본 켬)면 뒤에서 내려받아 두었다가 쉬는 틈에 저절로 설치하고 다시 켠다: 앱 안 Claude · 내보내기 같은 일이 없고, 앱 밖 Claude Code 가 2분 넘게 조용하고, 창을 2분 넘게 떠나 있었거나 5분 넘게 손대지 않았을 때(슬라이드 · 입력칸에 커서가 있으면 기다린다). 다시 켜면 열어 두었던 덱을 다시 연다.
  칩의 「설치하고 다시 켜기」로 바로 받을 수도 있다. 창으로 돌아왔을 때 30분 넘게 안 봤으면 한 번 더 본다. 「설정 › 업데이트」에서 자동 확인 · 자동 설치를 끄고 켠다. 개발 실행에서는 확인하지 않는다.
- 업데이트 주소는 `tauri.conf.json` 의 `plugins.updater.endpoints` (`a7garden/claudeppt` 의 최신 릴리즈).
- 서명 키는 `~/.tauri/claudeppt.key`(비밀번호 없음). 저장소 비밀 `TAURI_SIGNING_PRIVATE_KEY` 에 같은 내용을 넣는다.
- 저장소 비밀이 없으면 CI 는 빌드를 건너뛴다. 그때는 키가 있는 PC 에서 서명 키를 주고 `npm run tauri build` 를 돌린 뒤 `git push origin main && node tools/release-local.mjs`: 설치 파일 · 서명 · `latest.json` 을 `v<버전>` 릴리즈로 올린다 (2026.11.18 0.1.1 을 이 길로 냈다).
  **키를 잃으면 이미 깔린 앱은 더는 업데이트를 받지 못한다**: 공개 키가 앱 안에 박혀 있다.
